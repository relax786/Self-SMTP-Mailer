# Self SMTP Mailer

A modern desktop SMTP email client built with Python.

## Features

- Modern dashboard
- SMTP sender profiles
- Multiple SMTP providers
- SSL / STARTTLS
- Sender profile editing
- SMTP connection testing
- Email templates
- Recipient groups
- Draft management
- Email history
- Attachments
- Activity logs
- Local credential storage
- SQLite database
- Refresh controls
- Dark modern UI

## Supported SMTP

- Gmail / Google Workspace
- Microsoft 365 / Outlook
- Yahoo Mail
- iCloud Mail
- Custom SMTP servers

## Installation

Clone the repository:

```bash
git clone https://github.com/relax786/Self-SMTP-Mailer.git
cd Self-SMTP-Mailer

## Create a virtual environment:

python3 -m venv .venv
source .venv/bin/activate

## Install dependencies:

pip install -r requirements.txt

## Run:

python smtp_mailer.py
